§ S · CENTRAL SEARCH

Одна строка — десятки инструментов. Тип цели определяется автоматически, его можно сменить вручную. «Живая разведка» делает прямые запросы к открытым API (DNS, RDAP, Wayback, Wikipedia, GitHub и др.) прямо из браузера.

Хранилище Obsidian

Подключите папку хранилища GOD EYE, чтобы читать заметки как записи и записывать записи сайта как заметки. Работает в Chrome и Edge. В других браузерах используйте импорт папки и экспорт ZIP.

Хранилище данных и резервные копии

Данные сохраняются автоматически в локальной базе IndexedDB браузера (без лимита 5 МБ). Для переноса и долгосрочного хранения используйте зашифрованный бэкап .gebackup (AES-256-GCM).
