# GOD EYE v3.2.0 — OCULUS PRIME

Личная система анализа **открытых источников** (OSINT) с модулем **GEOINT 3D Earth v3.2** (осмотр улиц и номеров домов до Z21 + прогулка 360°) и полноэкранным **Детективным Штабом** (`case-studio.js`) для расследования холодных преступлений и личных забытых дел. Работает целиком в браузере: без сервера, без регистрации, без платных сервисов. Данные хранятся только в вашем браузере (IndexedDB).

Оформление: чёрный, серебро, бордо, тактические сетки в стиле Obsidian и OSINT. Звук и анимация включаются кнопкой «Разбудить око» (браузеры не разрешают звук без клика).

## Как опубликовать

1. Опубликуйте корень репозитория (`index.html`, `geo3d.js`, `case-studio.js`, папки `assets/` и `vendor/`) на GitHub Pages.
2. Дождитесь обновления GitHub Pages и нажмите `Ctrl+Shift+R`.

Папка `vendor/` содержит локальные копии MapLibre GL, Leaflet и `satellite.js`, чтобы 2D-карта, орбиты спутников и 3D-глобус мгновенно открывались без зависимости от зарубежных CDN. `worker.js` нужен только если вы поднимаете свой прокси на Cloudflare.

### Плагины поиска

Вкладка **Поиск → Плагины**: 45 источников живой разведки с переключателями, описанием «куда уходит запрос» и кнопкой проверки доступности. Каждый плагин обращается к открытому API напрямую из браузера, без ключей:

- **Архивы и наука:** Internet Archive, Open Library, Crossref, OpenAlex, Wikimedia Commons
- **Профили и сообщества:** Hacker News, GitHub, Stack Overflow, Bluesky, Mastodon, Lemmy, Codeberg, npm, **WhatsMyName** (проверка никнейма на сотне сайтов через ваш прокси; знакомства, 18+, здоровье и политика исключены)
- **Сеть:** Cert Spotter, HackerTarget, сверка DNS (Cloudflare и Google), геолокация IP (ipinfo и ipwho.is), Tor Project, PeeringDB, проверка одноразовых почтовых доменов
- **Гео:** Википедия и Commons рядом с точкой, Open-Meteo, iNaturalist, USGS, NASA EONET, Photon
- **Уязвимости:** EPSS, NVD с признаком каталога CISA KEV
- **Блокчейн:** Blockscout (EVM), TON Center, Blockstream (Bitcoin)
- **Реестры и юрлица:** GLEIF (LEI, адреса, материнские структуры), Sirene (Франция), Brønnøysund (Норвегия)
- **Банки и платежи:** IBAN (контрольная сумма, разбор, банк через openiban), BIC, BIN (платёжная система; полные номера карт не принимаются)
- **Транспорт и устройства:** VIN (офлайн-разбор и NHTSA vPIC), MAC (производитель по базе IEEE)
- **Ссылки и организации:** oEmbed, Wikidata (карточка организации и владелец сайта), ссылки из Википедии
- **Космос:** CelesTrak

Свои ссылки-шаблоны с `{q}` добавляются там же («Мои источники») и появляются в общем списке из 360 с лишним движков.

Новые типы целей определяются автоматически: IBAN с верной контрольной суммой, `BIC DEUTDEFF`, `BIN 457173`, VIN из 17 знаков, MAC `AA:BB:CC:DD:EE:FF` или `OUI AABBCC`. Все результаты — справочные данные: по ним нельзя узнать владельца счёта, автомобиля или устройства.

### Аналитика дела

В карточке дела (раздел «Дела»):

- **Сводка «известно / неизвестно / противоречит»** собирается автоматически по полям дела: хронология, улики, фигуранты, открытые вопросы, неотработанные зацепки, противоречия. Копируется в Markdown или добавляется в заметки дела.
- **Матрица версий (ACH):** строки — улики, столбцы — версии из полей дела. В клетке ✓ согласуется, ✗ противоречит, ~ нейтрально. Версии ранжируются по взвешенному числу противоречий (вес берётся из оценки улики и меняется вручную), показываются улики, которые лучше всего различают версии. Матрица — порядок проверки, а не доказательство.
- **Независимость источников:** каждой ссылке ставится роль «первоисточник» или «перепечатка»; перепечатки и ссылки с одного сайта не считаются независимым подтверждением.
- **Копии и хеши:** поиск и сохранение копии в Wayback Machine, SHA-256 страницы с датой (страница скачивается через ваш прокси).
- **Подпись досье:** ключ ECDSA P-256 создаётся в браузере (закрытый ключ не выгружается). Подпись фиксирует поля дела, матрицу, хеши источников и список связей; любое последующее изменение дела видно. Файл подписи (`.json`) проверяется отдельно, в том числе на другом компьютере.

Сводка, матрица, список источников с хешами и сведения о подписи попадают и в автономное HTML-досье дела.

### Звук и атмосфера

Меню звука (кнопка OST в шапке) и **Настройки → Звук и саундтрек**:

- **CASEFILE NOIR** — написанная вручную пьеса в ре миноре (64 BPM, свинг, форма AABA на 32 такта): труба с сурдиной, электропиано, щётки, ходящий контрабас, в «мостике» вибрафон и струнный пэд. Каждый проход формы слегка меняется. Ноты ставятся по часам звука, темп не плывёт.
- **Атмосфера** — отдельные переключатели **Дождь** (капли, ветер, далёкий гром, капли на стекле на экране), **Лампа** (гул, мерцание, тёплое пятно света) и **Город** (машины по мокрому асфальту, сирена вдали). Работают с любым треком и без него, у них своя громкость.
- **Нуар в делах** — в разделе «Дела», в карточке дела и на доске музыка плавно переходит в CASEFILE NOIR, на выходе возвращается прежний трек (включается в настройках, работает при включённом OST).
- **Звуки дел:** «дело раскрыто» и «дело закрыто» при смене статуса, диктофон при сохранении правок, телефон при статусе «Горячий след». Прослушать можно в настройках.

### Фото-лаборатория 2.0

Раздел **Изображения**: метаданные EXIF, GPS, XMP, IPTC, структура JPEG и оценка качества, сравнение встроенного превью с кадром, ELA, перцептивный хеш. Ниже результатов:

- **Хронолокация:** положение Солнца, восход и закат, фаза Луны, проверка освещения кадра, согласованность часовых поясов, погода на дату (по кнопке), калькулятор «тень → время суток»
- **Обратный поиск:** копирует фото или выделенную область в буфер и открывает Lens, Яндекс, Bing, TinEye
- **Координаты:** DMS, UTM, MGRS, Plus Code, Geohash, Maidenhead и ссылки на карты
- **Связи в базе:** снимки той же камеры, времени и места
- **Приватность:** что файл рассказывает о вас; копия без метаданных с закраской лиц и номеров

## Приватность и безопасность

- Файлы (фото, документы) разбираются локально и никуда не отправляются.
- При включённой «Живой разведке» цель скана уходит в сторонние открытые сервисы напрямую из браузера. Список хостов виден на карточке каждого плагина. Выключатель: Настройки → Приватность.
- Шрифты загружаются с Google Fonts (раскрывают IP шрифтовому серверу).
- API-ключи (необязательные) хранятся только в браузере и не входят в резервные копии и отчёты об ошибках.
- Content Security Policy в `<meta>`, подпись SRI для Leaflet, `referrer: no-referrer`.
- Импорт резервных копий и Obsidian проходит проверку: известные типы записей, безопасные идентификаторы, только http(s) в ссылках. В CSV-экспорте формулы Excel нейтрализуются.
- Журнал ошибок живёт в браузере; кнопка «Скопировать отчёт» в Настройках не включает названия записей и ключи.

## Этика

Только законные публичные источники. В проекте нет функций взлома, обхода авторизации, поиска по утёкшим базам и распознавания лиц частных лиц. Найденные автопоиском профили получают статус **кандидат** и подтверждаются по двум независимым признакам: совпадение ника не доказывает, что это тот же человек. По активным делам о пропавших людях обращайтесь в полицию и официальные организации.

## Горячие клавиши

- `Ctrl+K` — командная палитра
- `Alt+M` — саундтрек
- Доска расследования: `V` выбор, `T` нить, `N` заметка, `D` документ, `L` метка, `P` фото, `B` из базы, `E` событие, `I` персона, `F` вписать

## Известные ограничения

- Публичные API иногда отвечают медленно или ограничивают число запросов; карточка покажет ошибку, кнопка ↻ повторит запрос.
- Instagram, TikTok, VK и Facebook из браузера проверить нельзя (нужны официальные API), для них есть ручные ссылки.
- Расчёты Солнца и Луны приближённые (Солнце около 0,1–0,3°, Луна ±0,5 суток).
